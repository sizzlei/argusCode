## 새 기능

### 라이트 테마
- 설정 → 편집기 → **테마**에서 다크 / 라이트를 고를 수 있습니다. macOS의 창 제목 표시줄은 다시 시작하면 바뀝니다.

### 데드락 분석
- 데드락 기록을 붙여 넣고 `⌥⌘E`(Windows `Ctrl+Alt+E`)를 누르면 트랜잭션별 SQL, 보유·대기 락, 대기 관계, 롤백된 쪽, 원인 분석을 보여줍니다.
- MySQL / Aurora(`SHOW ENGINE INNODB STATUS`, 에러 로그), PostgreSQL(서버 로그), Oracle(ORA-00060 트레이스).

### 단축키 설정
- 설정 → **단축키**에서 명령별 단축키를 바꿀 수 있습니다. 겹치는 명령은 자동 해제되고, 메뉴에도 바로 반영됩니다.

### DDL 정렬
- 문서 정렬(`⇧⌥F`)이 ALTER TABLE(동작별 한 줄, 컬럼·타입 정렬), CREATE VIEW … AS SELECT, CREATE INDEX·DROP·COMMENT ON도 정리합니다.

## 개선
- macOS: 앱 번들에 서명해, 실행할 때마다 폴더 접근을 다시 묻던 문제를 고쳤습니다.
- 가이드 페이지에 스크린샷과 데드락 분석 페이지를 추가했습니다.
