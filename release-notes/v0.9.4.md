## 새 기능

### SQL 문법 검사
SQL을 쓰는 동안 틀린 부분을 **드래그 선택처럼 박스로** 표시합니다. 마우스를 올리면 이유가 나오고, `F8` / `⇧F8`로 다음·이전 문제로 이동합니다. 상태 표시줄의 `문법 ✕ n ⚠ m`을 눌러도 이동합니다.

- **빨간 박스(오류)**: 닫히지 않은 괄호·따옴표·주석, 키워드 오타(`SELCET`, `FORM`, `WHER`, `GRUOP BY`…), `FROM` / `)` 앞에 남는 쉼표, 쉼표 두 번, 비어 있는 `WHERE` / `AND` / `OR` 조건
- **노란 박스(주의)**: `WHERE` 없는 `UPDATE` / `DELETE`, `ON` 없는 `JOIN`, `= NULL` 비교, `;` 없이 이어진 두 문장

방언마다 문법이 다른 부분은 검사하지 않고, 어느 DB에서나 틀린 것만 잡습니다. 프로시저·`DELIMITER` 블록은 괄호·따옴표만 확인합니다. 설정 → SQL → **SQL 문법 검사**로 끌 수 있습니다.
