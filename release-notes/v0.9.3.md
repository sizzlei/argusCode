## 새 기능

### 롤백 스크립트 만들기
- 작업 DDL을 연 상태에서 우클릭 → **롤백 스크립트 만들기 (새 탭)** (보기 메뉴에도 있음). 선택 영역이 있으면 그 부분만 되돌립니다.
- 작업 문장을 역순으로 되돌리는 SQL을 만듭니다: CREATE → DROP, ADD COLUMN·INDEX → DROP, RENAME → 반대 방향.
- MODIFY / CHANGE / DROP COLUMN·INDEX는 폴더 안 DDL의 **변경 전 정의**로 되돌리고, 어느 파일 몇 번째 줄에서 가져왔는지 주석으로 남깁니다.
- 원래 정의를 모르거나 되돌릴 수 없는 작업(TRUNCATE, DROP TABLE의 데이터 등)은 추측하지 않고 `⚠ 확인 필요` / `✕ 자동으로 되돌릴 수 없음`으로 표시합니다.
- MySQL · PostgreSQL · Oracle 문법을 지원합니다.

### 온라인 DDL 영향
- DDL 검토 패널에 ALTER TABLE / CREATE INDEX의 예상 실행 방식을 함께 보여줍니다. 규칙 파일이 없어도 동작합니다.
  - MySQL 8.0 / Aurora MySQL 3: INSTANT · INPLACE · 테이블 재구성 · COPY(쓰기 차단)
  - PostgreSQL: 테이블 재작성 · 쓰기 차단 · CONCURRENTLY 여부
  - Oracle: ONLINE 여부, 컬럼 삭제·NOT NULL 추가 등
- 쓰기를 막는 작업은 경고로 표시하고, 메타데이터 락·긴 트랜잭션 등 주의할 점을 알려줍니다.
- 폴더 DDL의 변경 전 정의를 보고 `VARCHAR` 길이 변경이 255바이트 경계를 넘는지(COPY)도 구분합니다.
- 설정 → DDL 검토 → **온라인 DDL 영향 표시**로 끌 수 있습니다.

## 개선
- 오른쪽 패널(DDL 검토 · 실행계획/데드락 · Markdown 미리보기)의 너비를 경계선을 드래그해 바꿀 수 있습니다. 패널 종류별로 기억하고, 경계선을 더블클릭하면 기본 너비로 돌아갑니다.
