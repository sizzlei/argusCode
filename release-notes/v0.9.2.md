## 새 기능

### 자동 업데이트
- 새 버전이 나오면 알림으로 알려주고, **지금 업데이트**를 누르면 내려받아 설치합니다. **다시 시작**하면 새 버전이 열립니다(저장하지 않은 파일이 있으면 먼저 물어봅니다).
- 파일 메뉴 → **업데이트 확인…**, 설정 → 정보 → **업데이트 확인** / **릴리스 노트**.
- 시작할 때 몇 시간에 한 번 확인합니다. 설정 → 정보 → **시작할 때 업데이트 확인**으로 끌 수 있습니다.
- 내려받은 파일은 체크섬을 확인한 뒤 설치합니다.

### 업데이트 후 릴리스 노트
- 업데이트한 뒤 처음 실행하면 이 창처럼 바뀐 내용을 보여줍니다.

## 참고
- 자동 업데이트는 이 버전부터 동작합니다. 이전 버전에서는 한 번만 직접 설치해 주세요.
- macOS: 앱이 있는 폴더(보통 `/Applications`)에 쓸 권한이 있어야 합니다. 권한이 없으면 내려받기 페이지로 안내합니다.
